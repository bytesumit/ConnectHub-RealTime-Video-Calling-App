# ConnectHub 💬🎥  
**Real-Time Video Communication Web App**

ConnectHub is a modern, full-featured web application for real-time video calling, chatting during calls, and screen sharing. Built using powerful technologies like **React.js**, **Node.js**, **WebRTC**, and **Socket.IO**, it provides a smooth and secure communication experience with an elegant UI enhanced by **Framer Motion** animations.

---

## 🚀 Features

- 🔐 **User Authentication & Authorization**  
  - Secure login/signup using **JWT** and **bcryptjs**  
  - Session management and protected routes

- 📹 **Real-Time Video Calling**  
  - Peer-to-peer connections via **WebRTC**  
  - Smooth call initiation and termination

- 💬 **Chat During Calls**  
  - Integrated real-time chat with message delivery via **Socket.IO**

- 🖥️ **Screen Sharing**  
  - One-click screen sharing feature during video calls

- 🎨 **Modern UI with Animations**  
  - Built with **React.js** and styled using **Bootstrap**  
  - Beautiful transitions and interactive elements using **Framer Motion**

- ☁️ **Backend & Database**  
  - RESTful API built on **Node.js**  
  - Real-time signaling with **Socket.IO**  
  - Data stored securely in **MongoDB**

---

## 🛠️ Tech Stack

### Frontend:
- React.js
- Bootstrap 5
- Framer Motion
- WebRTC (for media streaming)

### Backend:
- Node.js
- Express.js
- Socket.IO
- MongoDB with Mongoose

### Authentication:
- JWT (JSON Web Token)
- bcryptjs (password hashing)
